# 虚构案例：不同岗位如何判断

以下人物、公司和岗位均为虚构，只展示取证方法，不构成真实招聘信息或可直接发送的招呼。

## 例 1：制造企业设备维护岗

**JD 摘要：** 负责产线设备点检与故障处理；要求能接受倒班，持有电工证者优先。

**求职者材料：** 有两年设备巡检记录和故障工单经验；没有提供倒班意愿或证书信息。

**正确判断：** 点检经验属于直接实践；故障处理需要看本人独立排障的例子；倒班条件为信息不足。JD 的“电工证优先”不能直接改成企业的硬门槛，但若实际工作包含依法须持证的操作，应另查当前规定并核对证书。招呼应写点检和工单证据，不应自称持证或“精通所有产线设备”。

## 例 2：连锁门店店长岗

**JD 摘要：** 负责排班、培训、库存和门店经营指标。

**求职者材料：** 曾协助店长排班，独立做过新人带教；没有团队管理人数、库存盘点责任或经营指标结果。

**正确判断：** 排班为相近可迁移，带教为直接实践；独立管理门店和经营结果缺少证明。不能把“协助店长”写成“独立负责门店运营”，也不能只因有服务经验就判定管理能力满足。

**招呼草稿：** 您好，我有连锁门店一线服务经验，做过新人带教，也协助店长处理过排班。看了这个岗位，了解到工作涉及团队排班、培训和日常运营；其中带教与排班协作是我实际做过的部分。方便的话，我可以把简历发您，进一步了解门店的具体分工。

这段招呼没有虚构经营指标或独立带店经历。实际投递前，还应核对 JD 是否把独立管理经验列为必须条件。

## 例 3：需要执业资格的岗位

**JD 摘要：** 要求相关专业资质与有效执业资格，并承担现场专业判断。

**求职者材料：** 有相近专业学历和实习经历，但未提供资格证书或注册状态。

**正确判断：** 执业资格是需要单独核对的关键条件，状态为信息不足；学历和实习不能替代有效资格。具体资格要求应以该岗位 JD 及当前权威规定为准。核实前不应给出“满足硬门槛”的结论或可直接发送的资格主张。
